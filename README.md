# 指间 · 美甲试色

照片双手试色工具，包含 120 个照片色号、十指独立配色、肤色调节、缩放、平移及图片导出。

## 手机与电脑适配

同一个页面会根据屏幕宽度自动切换布局。手机版保留照片双手和十指独立配色，底部按钮展开全部 120 色；支持色号搜索、效果筛选、拖动平移和双指缩放。电脑版保留两侧颜色库。

## 背景颜色

展开手模下方的「背景颜色」，可选 20 个常用色块，也可使用自选颜色调色板或输入六位 HEX 色值。支持恢复默认，背景选择自动保存在当前浏览器，导出的试色图片也包含所选背景。

## 光线模拟

手模下方提供原图、柔光、顶光、左侧光、右侧光和背光，可调节光线强度与方向。按住「按住看原图」可临时对照，松开恢复当前光线；「恢复原图」清除光线模拟。光线设置会保存在当前浏览器，导出图片使用当前效果。

此功能基于静态照片近似模拟明暗和局部反光，不是实物材质或三维光学测量，无法完整还原猫眼随观察角度变化的效果。

## 下载后直接使用

1. 点击 GitHub 页面的 **Code → Download ZIP**。
2. 解压整个文件夹。
3. 用新版 Edge、Chrome 或 Safari 打开根目录的 **index.html**，即可试色，无需安装依赖、无需 API 密钥，也无需联网。

电脑可直接双击打开。手机需先解压，再使用支持本地 HTML 的浏览器打开；部分手机文件管理器的预览不支持完整交互，可改用静态网站托管后的网页地址。GitHub 仓库页面本身不直接运行工具。配色保存在当前浏览器；清除浏览器数据后可能丢失。

## 效果说明

使用当前确认的照片手模，左右手为同一张手部照片的镜像。猫眼、闪粉、亮片保留原色板照片纹理；这是静态照片预览，不提供真实三维或随角度变化的光学模拟。现场光线、显示器及实际涂层会影响颜色。

## 与 AI 软件连接

本仓库的 ZIP 是独立网页工具及源码包，不是适用于所有 AI 软件的一键插件。将 ZIP 上传到聊天窗口也不会自动安装。AI 内嵌版本需要支持 MCP Apps 界面的客户端，以及单独部署和配置 MCP 服务。当前私人 ChatGPT 应用的账户权限和凭证没有包含在本仓库中。
